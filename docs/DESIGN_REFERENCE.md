# COGIA 365 — référence visuelle officielle

Le design de COGIA 365 Studio doit rester aligné sur les références fournies par le propriétaire du produit le 13 octobre 2026.

## Identité

- Logo officiel : `assets/cogia-365-official.png`
- Signature : « Solutions intelligentes pour un impact durable »
- Le logo doit rester visible dans la navigation principale et sur l’écran de connexion.

## Interface de référence

- Maquette source : `assets/references/cogia-365-interface-reference.png`
- Composition : navigation blanche à gauche, espace COGIA Agent au centre, informations contextuelles à droite.
- L’espace central comprend l’accueil personnalisé, quatre actions rapides, les exemples de questions et le compositeur de l’Agent.
- Palette dominante : blanc, bleu profond, bleu électrique, avec des cartes pastel bleu, vert, jaune et rouge.
- Toute évolution doit préserver les fonctions existantes, la lisibilité et l’adaptation ordinateur, tablette et mobile.
